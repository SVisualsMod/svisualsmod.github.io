УСТАНОВКА

Четыре простых шага.

  1. Установите Fabric Loader для выбранной версии Minecraft.
  2. Установите Fabric API для той же версии.
  3. Поместите SVisuals .jar в папку mods.
  4. Запустите Minecraft через Fabric.
%APPDATA%\.minecraft\mods

В стороннем Minecraft launcher используйте папку mods вашего игрового профиля.

Коротко о главном.

Нужен аккаунт?+

Нет. Мод, локальные настройки и скачивание публичных CFG доступны без аккаунта. Вход нужен для публикаций, оценок и комментариев.

Нужен интернет?+

Только для онлайн-каталога и скачивания. Если API недоступен, локальные функции продолжают работать.

Где мои старые конфиги?+

Они не удаляются. CFG хранится в config/svisuals/profiles внутри вашего игрового профиля.
